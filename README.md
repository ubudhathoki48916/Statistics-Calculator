# Statistics Calculator Using Three Programming Paradigms

## Project Overview
This project calculates the mean, median, and mode of a dataset using three programming languages and programming paradigms: C (procedural), OCaml (functional), and Python (object-oriented).

## Dataset
The dataset used in all three implementations is:

[4, 2, 7, 2, 9, 4, 2, 6]

## Results
All three implementations produce the following results:

- **Mean:** 4.50
- **Median:** 4.00
- **Mode:** 2

## Programming Languages
- **C:** Uses functions and procedural programming.
- **OCaml:** Uses functional programming techniques.
- **Python:** Uses a StatisticsCalculator class and methods.

## Project Structure
- C/ - C source code
- OCaml/ - OCaml source code
- Python/ - Python source code
- screenshots/ - Screenshots showing program output
- eport/ - Assignment report

## How to Run

### C
Compile C/statistics.c using a C compiler, then run the compiled program.

### OCaml
Run OCaml/statistics.ml using an OCaml environment.

### Python
Run the following command from the project directory:

python Python/statistics.py
